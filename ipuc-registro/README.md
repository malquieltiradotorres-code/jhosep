# Registro · IPUC

Plantilla sencilla para registrar personas en la Iglesia Pentecostal Unida de Colombia: solo **nombre completo** y **número de teléfono**.

- Lista numerada con buscador, botón de WhatsApp, editar y eliminar.
- Descargar Excel, imprimir la lista o una planilla en blanco para llenar a mano.
- Copia de seguridad para pasar los registros a otro equipo.

Los datos se guardan en el navegador del dispositivo donde se registran; no se suben a GitHub.
