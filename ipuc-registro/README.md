# Registro de Visitantes · IPUC

Plantilla web para registrar a las personas que visitan la congregación de la Iglesia Pentecostal Unida de Colombia.

## Qué hace

- Formulario rápido: nombre, teléfono/WhatsApp, edad, dirección o barrio, quién lo invitó, fecha, servicio, si es su primera vez, petición de oración y si desea visita.
- Después de cada registro el formulario se limpia y deja la misma fecha y servicio, para anotar a muchas personas seguidas.
- Lista con buscador y filtros (hoy, últimos 7 días, este mes, primera vez, desean visita).
- Botón de WhatsApp en cada visitante con un saludo ya escrito.
- **Descargar Excel** (archivo .csv que abre en Excel).
- **Imprimir lista** y **Planilla en blanco** para imprimir y llenar a mano.
- Copia de seguridad y restauración para pasar los registros a otro equipo.
- Casilla de autorización de datos (Ley 1581 de 2012).

## Dónde se guardan los datos

En el navegador del dispositivo donde se registran (localStorage). No se suben a GitHub ni a ningún servidor. Por eso conviene descargar el Excel o la copia de seguridad cada cierto tiempo.

## Cambiar el nombre de la congregación

Toca el nombre que aparece debajo de "Registro de Visitantes" en el encabezado.
